## What the bucket holds, and what it never holds

The bucket holds **stored models** and **open-data snapshots** (the data files as downloaded) only, each at its path inside the
repository (`scripts/release/fetch_artifacts.py` places them there).

It never holds:

- challenge data: the organiser files are not redistributed;
- anything keyed by the challenge's row IDs (`MVT_ID_mvt`): feature blocks, caches, matrices, predictions;
- ADS-B positions or anything derived from them (stage-1 tables, feature blocks, travel-time maps, trajectory
  store), which would be ODbL derived databases.

These are rebuilt by the commands in [`REPRODUCTION.md`](REPRODUCTION.md#4-rebuilding-the-2025-inputs).
